## 📋 Prompt para pegar

```text
Vas a hacer mi revisión semanal. Lee primero:

- marco://current
- marco://projects
- marco://decisions

Después, ejecuta esta plantilla:

## 1. Estado de cada proyecto
Para cada proyecto en marco://projects, dime:
- Estado actual (🟢/🟡/🔴)
- Última actividad conocida
- ¿Está alineado con el plan de marco://current?

## 2. Decisiones recientes
Lee las últimas 5 entradas de marco://decisions. ¿Hay alguna
que ya no aplique o que necesite revisión?

## 3. Bloqueadores
De marco://current, extrae los bloqueadores. Para cada uno:
- ¿Se puede resolver esta semana?
- ¿Qué necesitas para destrabarlo?

## 4. Sugerencia de foco
Con base en todo lo anterior, ¿cuál debería ser mi foco
la próxima semana? Justifica en 2 líneas.

## 5. Pregunta incómoda
Hazme una pregunta que probablemente estoy evitando.

Responde directo, sin adornos.
```
