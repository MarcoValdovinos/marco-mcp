## 🔴 Bug crítico

En `api/kodice.js`:

```js
const { privateKey, publicKey } = crypto.generateKeyPairSync("ed25519");
```

**Problema:** esto se ejecuta en el scope del módulo. En Vercel serverless,
cada cold start regenera las llaves. La verificación con `KODICE_PUBLIC_KEY`
falla siempre. **No-repudio roto.**

**Fix:** mover generación a script aparte, cargar desde ENV:

```js
const privateKey = crypto.createPrivateKey({
  key: process.env.KODICE_PRIVATE_KEY.replace(/\\n/g, '\n'),
  format: 'pem',
  type: 'pkcs8'
});
```
